  • 處理「均給分」、「一律給分」

~10分鐘 / 9 份（含截圖時間）

🌟 額外大優勢：題庫永遠在你手上、永遠可改

傳統用 Anki：要改題目就得在 Anki 視窗內一張一張點開來改，沒有版本控制、不能批次處理、不能用 Claude 幫忙批次改。

用這個流程：你的「題庫真相」是 Obsidian 內的 .md 純文字檔。這代表：

✍️
在 Obsidian 內直接改
  • 找錯字、改答案、補 tag 全在 .md 內
  • 用 Obsidian 強大的搜尋 / 取代
  • 用 backlink 看哪些題都涉及同一個疾病
  • 用 graph view 看 tag 之間的網絡
  • 改完 sync 一次，Anki 卡自動 update
🤖
叫 Claude 幫批次改
  • 「114-2-6 Q15 tag 漏標 hyperkalemia」
  • 「所有 OBGYN 考古加 [[OBGYN 重點]] tag」
  • 「113-2-6 Q47 答案應該是 D，改一下」
  • 「掃描醫學六，挑出所有圖片題列清單給我」
  • 「醫學三所有 [[gout]] 題目 cross-link 到我的痛風筆記」
💡 關鍵差異：傳統 Anki 一旦做好卡，要「批次調整」幾乎不可能（除非寫 add-on）。這個流程的卡片源頭是 .md 純文字，Claude 可以批次掃描、批次替換、批次補 tag——你只要用嘴巴說就好。等於把題庫的「維護與優化」也自動化了。

🕸️ 隱藏寶藏：wikilink 自動長出「原子筆記」知識網絡

Claude 在生卡片時會做一件 Anki 完全沒有的事——把題目中文敘述（像「心肌梗塞」、「高血鉀」、「呼吸困難」）自動轉成英文專有名詞，再包成 [[wikilink]]。

它的好處：每個 [[xxx]] 就是一個「原子筆記」種子
  1. 題目末尾的 [[myocardial infarction]] → 在 Obsidian 內變成可點 link
  2. 點下去 → Obsidian 自動建立 myocardial infarction.md，這就是一個新的概念筆記
  3. 之後所有題目提到 MI 都會 backlink 到這份筆記
  4. 打開 Graph View → 整個 vault 像一張概念星雲，越常考的疾病節點越大

醫學六 9 份共 720 題，產出約 3500 個 wikilink（平均每題 ~5 個），跨 6 科自動串聯。

Part A · 一次性環境準備

🃏 Part A：裝 Anki + AnkiConnect

A1. 下載並安裝 Anki 主程式

  1. 到 https://apps.ankiweb.net/ 下載對應你作業系統的版本（Mac、Windows、Linux 都可）
  2. 安裝完打開 Anki，第一次會問你要不要建立 AnkiWeb 帳號 —— 建議建一個，可以雲端同步到手機
  3. 看到主畫面（左側「牌組 / Decks」列表、上方「新增 / Add」按鈕等）就表示安裝完成

A2. 其他基礎安裝看這支影片就好（10 分鐘）

💡 不重複造輪子。YouTuber「醫學生 J」已經做了非常清楚的 Anki + Obsidian + AnkiConnect + Obsidian to Anki plugin 全套安裝教學，照影片做就行。

📺 影片連結：https://youtu.be/S0fDdArNtRo

影片裡會教你：

  • ✅ 在 Anki 內裝 AnkiConnect addon（代碼 2055492159）+ webCors 白名單設定 + 重啟
  • ✅ 下載安裝 Obsidian、建 vault
  • ✅ 在 Obsidian 開啟 Community plugins → 裝 Obsidian to Anki plugin
  • ✅ Plugin 與 Anki 的初步連線測試

📋 影片裡會叫你設定的程式碼（直接複製貼上）

影片教到下面三個設定時，你會需要這些 code。先存著，到時候 copy-paste 即可（不用自己手打）。

▸ AnkiConnect Config JSON（允許 Obsidian 連線）⚠️ 必做

到 Anki → 工具 / Tools → 附加元件 / Add-ons → 選 AnkiConnect → 右側按 設定 / Config。把整個 JSON 內容覆蓋成下面這份（重點是 "webCorsOriginList" 內要有 "app://obsidian.md"）： 

{
  "apiKey": null,
  "apiLogPath": null,
  "ignoreOriginList": [],
  "webBindAddress": "127.0.0.1",
  "webBindPort": 8765,
  "webCorsOriginList": [
    "http://localhost",
    "app://obsidian.md"
  ]
}

按 確定 / OK 後，🔄 完全結束 Anki 再重開（Mac 上 ⌘Q，不要只關視窗）。

⚠️ 沒做這個 JSON 設定 = Obsidian sync 時跳「Failed to connect to AnkiConnect」。影片可能有教，但很容易漏，務必確認。

▸ 兩條 Custom Regexp（放到 plugin 設定 → Custom Regexp）

讓 #flashcard 與 #clozecard 兩種 tag 都能正確觸發 Anki 卡片：

((?:[^\n][\n]?)+) #clozecard ?\n*((?: \n(?:^.{1,3}$|^.{4}(?<!<!--).*))+)
((?:[^\n][\n]?)+) #flashcard ?\n*((?: \n(?:^.{1,3}$|^.{4}(?<!<!--).*))+)

▸ Anki 卡片背面模板（讓卡背顯示 Obsidian Link + Context）

到 Anki → 工具 / Tools → 管理筆記類型 / Manage Note Types → 選 Basic 或對應 note type → 卡片 / Cards → 編輯「背面範本」貼上：

{{FrontSide}}

<hr id=answer>

{{背面}}
<br><br><br>

<div style='font-size: 12px;'>{{Obsidian Link}}{{Obsidian Context}}</div>
⚠️ 用這個模板前，Anki Note Type 必須先有以下 4 個 field：
  • Front（卡片正面）
  • 背面（答案內容）
  • Obsidian Link（plugin 自動寫入 source link）
  • Obsidian Context（plugin 自動寫入 file path / heading 路徑）
到 Anki → 工具 / Tools → 管理筆記類型 → 選 note type → 欄位 / Fields → 新增 把缺的補上。

A3. 影片後唯一還要你動手做的事：在 vault 建好「科目」層資料夾

💡 影片裡教的 AnkiConnect 安裝 + 白名單 + 重啟、Obsidian 安裝、plugin 安裝這些都已涵蓋了，跟著影片做完就好。下面只剩你要在 Obsidian vault 內準備好資料夾結構，之後 skill 才知道要把 .md 存到哪。

在 vault 內建好「科目」層資料夾（只到科目就好）

🎯 你只要手動建到「科目」這一層就好，剩下子資料夾全部由 skill 自動建立！

在你的 Obsidian vault 內建立以下資料夾（左側 file explorer 右鍵 → New folder）。只需建到「醫學三/四/五/六」這層空資料夾即可，每份考古題的子資料夾（如 115-1-6/）+ .md 檔，全部由 Claude 自動建立。

Skill 跑完後會自動長出每份考卷的子資料夾與 .md：

💡 路徑可以自訂，但 Part B 的 Folder Table 要對應你的真實路徑。本說明書都用 考古/歷屆考古/醫學X 為例。
Part B · 一次性環境準備

🔌 Part B：Obsidian to Anki 客製化設定（必做）

影片裡只教 plugin 安裝，但 plugin 內幾個關鍵設定一定要客製化，否則：(1) sync 會卡住、(2) 卡片進錯 deck、(3) 在 Anki 內看到卡片時無法跳回 Obsidian source。

到 設定 / Settings → 左欄滾到下方點 Obsidian to Anki。以下設定全部都在這頁。

B1. Scan Directory（通常可不填）

到設定頁的 Defaults 區段，找 「Scan Directory」（欄位下方說明：The directory to scan. Leave empty to scan the entire vault）。

💡 一般可以留空（plugin 會掃整個 vault）。但如果遇到：
  • sync 太慢或卡在「Scanning vault...」
  • plugin 找不到考古題 .md 檔
就把這欄填上你想限定的範圍，例如： 
考古/歷屆考古/醫學六
把搜尋範圍縮小，sync 會穩定很多。

B2. Folder Table（核心設定）⚠️ 必做

這個就是讓「Obsidian 資料夾 ↔ Anki Deck」對應的核心設定。建議「每份考卷 = 一個 Anki 子 deck」，這樣在 Anki 內可以針對某次考古題單獨複習。

建議的命名規則

用 :: 在 Anki 內建立階層 deck（Anki 的標準語法）：

國考考古題
  └── 醫學六考古題
        ├── 115-1
        ├── 114-2
        ├── 114-1
        └── 113-2 ...

完整操作流程

  1. 先在 Anki 內建好 deck（建一次，之後增加新考古題只要重複此步驟即可）：
    • 到 Anki 主畫面 → 滑鼠右鍵點任一現有 deck → 看到右側齒輪 → 選項 或 重新命名
    • 輸入：國考考古題::醫學六考古題::115-1（用 :: 分層）
    • 確定後 deck 就會自動分層顯示
  2. 確認 deck 完整路徑：右鍵點該 deck → 重新命名 → 跳出視窗中會顯示完整路徑，選取全部 → 複製
  3. 到 Obsidian to Anki 設定：滑到 「Folder settings」→「Folder Table」 區段
  4. 新增一行對應關係：
    • 左邊欄：填 Obsidian 內考古題 .md 所在資料夾路徑，例如 考古/歷屆考古/醫學六/115-1-6
    • 右邊欄：貼上剛複製的 Anki deck 完整路徑，例如 國考考古題::醫學六考古題::115-1
  5. 每份考卷重複步驟 1-4（共 9 行對應，例如做完醫學六全部）

範例對應表（醫學六 9 份）

Obsidian 資料夾路徑（左）Anki Deck 完整路徑（右）

考古/歷屆考古/醫學六/114-2-6國考考古題::醫學六考古題::114-2

考古/歷屆考古/醫學六/113-2-6國考考古題::醫學六考古題::113-2
… 依此類推到 111-1-6 / 111-1

Part C · 每份考古題的流程

⚡ Part C：開始用 skill 生卡（用我們真實的醫學六實況示範）

以下實況是 2026-05-25 處理 9 份醫學六考古題（111-1-6 到 115-1-6）的完整對話過程。每一步你都可以照抄。

💡 你會發現你動手的部分其實超少：步驟 3（拖檔 + 一句指令）、步驟 5（回答 3 個問題）就結束了，總共動手不到 3 分鐘。步驟 6 是 Claude 在跑，你可以去做別的事。

1準備考古題檔

到考選部歷屆試題頁面下載對應科目的 PDF 試題。 檔名建議維持 114-2-6.pdf 這種格式（年份-次數-科目編號）方便辨識。

科目編號：3 = 醫學三、4 = 醫學四、5 = 醫學五、6 = 醫學六。

怎麼把檔案給 Claude（按方便程度排序）：

⚡ 推薦：直接拖檔（最方便）

把下載的 PDF（或 RTF / DOCX / MD）直接拖進 Cowork 對話框 → 下指令。Skill 內建多格式 parser，會依副檔名自動選對的解析方式（PDF 走 pdfplumber、RTF 走 striprtf、DOCX 走 python-docx、MD/TXT 直接讀）。

📂 推薦：給檔案路徑（不必拖）

如果檔案已經放在 vault 內，不用拖，直接告訴 Claude 路徑就好。Claude 也會主動問你「輸入檔案的完整路徑」與「輸出資料夾的完整路徑」（Step 0 必問）。

💡 怎麼複製 Obsidian 內的檔案路徑：在 Obsidian 左側檔案瀏覽器右鍵 → 選「複製 vault 路徑 / Copy vault path」，就會把路徑複製到剪貼簿，直接貼進對話框給 Claude。

💰 進階備案：用 pdf2md 預先轉成 markdown（極大量批次才划算）

以前 skill 只支援 RTF 時，PDF 必須先外部轉檔。現在 skill 內建 PDF parser，這條路徑用不到。但如果你要一次塞 20+ 份大型 PDF，可以考慮先用 pdf2md.morethan.io 把 PDF 轉成 markdown 存進 vault，再給 Claude 路徑——可以省一些 PDF parsing 的 token。日常用直接拖 PDF 就行。

2打開 Cowork + 把 vault 拖進來（檔案權限 Claude 會自己問）

在 Claude desktop app 開啟 Cowork mode。不用先做複雜設定——把考古題拖進對話框、下指令就好，Claude 跑到需要寫檔時自己會跳出來請求 vault 權限，你按「允許」即可。

💡 實況：就像你這次給我的指令「醫學六 / /anki-flashcard-medical-exam / 要跟我要 OB 權限」一樣——加一句「要跟我要 OB 權限」就會讓 Claude 早期確認權限，避免做到一半才卡住。如果 Claude 跑到一半說「找不到 vault」，直接回「給你權限」，Claude 就會自己跳出存取請求視窗讓你授權。
⚠️ macOS 第一次授權時可能會跳兩次系統權限視窗（一次「資料夾存取」、一次「文件資料夾」），兩次都按允許，否則可能只有讀取沒有寫入權限。

3拖入考古題 + 下指令

把所有要做的考古題檔（PDF / RTF / Markdown / TXT / DOCX 都可以，可混用）一次拖進 Cowork 對話框（醫學六的話就是 9 份），然後輸入：

你
醫學六
/anki-flashcard-medical-exam
要跟我要 OB 權限

「要跟我要 OB 權限」這句是提醒 Claude 「等下需要存到 Obsidian vault，記得先問我要不要授權」。

4Claude 載入 skill 並請求 vault 權限

Claude
OB vault 已連線。確認一下流程：收到 9 份醫學六考古題：111-1、111-2、112-1、112-2、113-1、113-2、114-1、114-2、115-1。
醫學六科目編號是 6，所以代號會是 [[111-1-6]]、[[115-1-6]] 這樣...

5回答 Claude 的 3 個問題

skill 設計上會問三件事，依你的需求選擇即可：

Q1. 處理順序？

選 「9 份全部依序做完」（從舊到新做完最完整）。

Q2. 分批方式？

選 「一次 80 題」（最快，反正都是 Claude 在生）。

Q3. 科別 tag？

選 「先掃一份再列科別清單給我看」。Claude 會掃描其中一份題目，列出科別範圍給你確認。

以醫學六為例，掃完 115-1-6 後 Claude 會列出：

6Claude 開始生成，每份生完會驗證

Claude 會依序：

  1. 依副檔名選對應 parser：PDF 用 pdfplumber（必要時 fallback 到 PyMuPDF）、RTF 用 striprtf、DOCX 用 python-docx、Markdown/TXT 直接讀。所有格式都會先轉成純文字 .txt 再給 Claude 讀，避免大檔爆掉 token
  2. 讀完 80 題 + 答案表
  3. 把答案表的特殊註記（# 號、均給分、一律給分）解析出來
  4. 產生整份 80 題的 markdown，含 wikilink tag、科別 tag、圖片題標記
  5. 寫到 vault 對應路徑 考古/歷屆考古/醫學六/<代號>/<代號>.md
  6. 跑驗證指令確認題數、flashcard 標記、分隔符、圖片題數正確

🚨 故障排除

❌ Anki 跳 「Failed to connect to AnkiConnect」（無法連線到 AnkiConnect）

檢查：Anki 主程式必須開著。

❌ Scan Vault 卡在「Scanning vault...」不會結束

原因：Scan Directory 設成空白，plugin 試圖掃整個 vault。

解法：

  1. 強制關閉 Obsidian
  2. 重開後到 Settings → Obsidian to Anki
  3. 把 Scan Directory 設成具體的科目資料夾（如 考古/歷屆考古/醫學六）
  4. 再跑一次 Scan Vault

❌ 同步成功但 .md 完全沒長出 ID 註解

兩個常見原因，依優先順序檢查：

原因 1：Scan Directory 範圍太大或設錯 → 跟上一條同樣解法，縮小 Scan Directory 範圍。

原因 2：⚠️ 格式錯誤（很容易發生，之前搞到頭很痛的就是這個）。Obsidian to Anki plugin 的 regex 對格式超敏感，少一個空格、多一個換行就辨識不到。如果改過 .md 後該題沒長 ID，多半是這個原因。

📋 .md 格式規則（分三類：必要 / 建議 / 風格） 
[[年份-次數-X]]Q題號
題目原文
(A) 選項 A
(B) 選項 B
(C) 選項 C
(D) 選項 D #flashcard␣
答案（解釋）[[tag1]], [[tag2]], [[科別考古]]

---

[[年份-次數-X]]Q下一題
...

🔴 必要規則（plugin 真認的，違反 = sync 失敗）

  1. #flashcard 前後都要有半形空格，後面一個空格再換行（從 Custom Regexp 拆解出來： #flashcard ?\n）
    → 這是最常踩雷的。少一個空格 plugin 就不認
  2. #flashcard 那行下面緊接答案內容（不能空行、不能立刻 ---、不能立刻下一題）
  3. 答案行不能是 <!--ID:--> 開頭（plugin 同步後會自己加在最後，別手動刪或移位）

🟡 強烈建議（避免奇怪 bug）

  1. 題與題之間用 --- 分隔，前後各空一行
    → 不然連續多題的 regex 可能把第二題的題幹當成第一題的答案，整個解析錯亂
💡 最快解：如果發現某幾題格式爛掉，直接叫 Claude「113-2-6.md Q15-Q20 用 skill 標準格式重寫」，他會用 skill 內定義的格式重新輸出，貼回 .md 即可。

類別範例

不會標的東西

  • ❌ 答案後括號內的解釋說明（只掃題目主文 + 4 選項）
  • ❌ 診斷性檢查用藥（adenosine、dobutamine 等壓力試驗藥）
  • ❌ 手術 / 處置名稱（appendectomy、colonoscopy 等）
  • ❌ 影像檢查項目（X-ray、CT、MRI）
  • ❌ 從醫學知識推論但題目沒寫的內容
  • ❌ 過於泛化的詞（如 "cancer"，要標具體疾病名）
